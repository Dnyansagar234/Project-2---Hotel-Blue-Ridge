## 🏨 HOTEL BLUE RIDGE

### Multidisciplinary BIM Project | Architectural • Structural • MEP

Hotel Blue Ridge is a multidisciplinary Building Information Modelling (BIM) project focused on developing an integrated hotel building model using Autodesk Revit, ETABS and Navisworks.

The project combines architectural modelling, structural design coordination, MEP modelling and BIM visualization to demonstrate a practical building design and coordination workflow.

## 🚪 Parametric Hotel Room Door Family – Revit

Developed a reusable hotel room door family in Autodesk Revit 2021 with an editable room-number parameter. Changing the room number in the Properties Palette automatically updates the number displayed on the door.

**Key Features:**
- Editable room number parameter.
- Automatic display of the updated room number on the door.
- Reusable family for multiple hotel rooms.
- Custom door design with a wood finish and decorative details.

**Workflow:** Edit Room Number → Update Parameter → Door Display Updates Automatically.

## 🏗️ Structural Analysis – ETABS Using IFC Model
As part of the Hotel Blue Ridge project, I worked on the structural analysis workflow using an IFC model exported from Autodesk Revit and imported into ETABS Ultimate 18.1.1.

### Workflow

1. Developed the structural building model in Autodesk Revit.
2. Exported the structural model into IFC format.
3. Imported the IFC file into ETABS Ultimate 18.1.1.
4. Verified structural geometry, column and beam connectivity, and section properties.
5. Reviewed material properties and structural supports.
6. Prepared the model for structural loading and analysis.

### How to use the viewer

1. Click the link above. It opens in your web browser, and no software install is needed.
2. If you are asked to sign in, use a free Autodesk account.
3. Wait a few seconds for the model to load.

| Action | How |
|--------|-----|
| Rotate (orbit) | Left-click and drag |
| Pan | Hold the middle mouse button, or Shift + left-click, and drag |
| Zoom | Scroll the mouse wheel |
| Reset the view | Click the **Home** icon |
| Hide or isolate parts | Open the **Model Browser**, then right-click an item |
| Check dimensions | Use the **Measure** tool in the toolbar |
| Cut through the model | Use the **Section** tool |
| Separate the parts | Use the **Explode** tool |

On a phone or tablet, use one finger to rotate and two fingers to pan and zoom.
